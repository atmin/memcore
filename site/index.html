memcore

A palimpsest for agents.

memcore is long-term memory for the agents you work with, kept as plain markdown in git. The working tree holds what is true now, and history holds earlier beliefs. The memcore command does the git work for the agents. It runs the installed git, so you install nothing else.

Agents forget between sessions, so you repeat the same instructions again and again. Your attention is the scarcest resource in this work. memcore keeps what you teach your agents, so you never tell an agent the same thing twice.

Install

On macOS or Linux, choose one install method.

Homebrew

If you already use the shell installer, follow the steps to switch to Homebrew.

brew install atmin/tap/memcore

To update, run brew upgrade atmin/tap/memcore. If you want the desktop application, run memcore ui --install after installation and each upgrade.

Shell installer

curl -fsSL https://memco.re/install | sh

The script checks the SHA-256 of the download, installs memcore in ~/.local/bin and adds the desktop application. It needs no sudo. To update, run the installer again. Read the install script.

After either method, run command -v memcore. For Homebrew, the path should be $(brew --prefix)/bin/memcore. For the shell installer, it should be ~/.local/bin/memcore. Then set up the machine with your memory remote.

memcore init git@github.com:you/memory.git

Uninstall

Use the command for your install method. Both keep your memory repo.

Homebrew

memcore init --undo && memcore ui --uninstall && brew uninstall atmin/tap/memcore

Shell installer

curl -fsSL https://memco.re/uninstall | sh

For switching install methods or building from source, see the install guide.
