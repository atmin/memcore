memcore

A palimpsest for agents.

memcore is long-term memory for the agents you work with, kept as plain markdown in git. The working tree holds what is true now, and history holds earlier beliefs. The memcore command does the git work for the agents. It runs the installed git, so you install nothing else.

Agents forget between sessions, so you repeat the same instructions again and again. Your attention is the scarcest resource in this work. memcore keeps what you teach your agents, so you never tell an agent the same thing twice.

Install

On macOS or Linux, install memcore into ~/.local/bin, then set up a machine with your memory remote:

curl -fsSL https://memco.re/install | sh
memcore init git@github.com:you/memory.git

The script checks the SHA-256 of the download, and needs no sudo. It also adds memcore to your applications, as the window to review and push what your agents remember. Read the script before you run it. To update, run the first line again.

To uninstall memcore, run the line below. It keeps your memory repo.

curl -fsSL https://memco.re/uninstall | sh
